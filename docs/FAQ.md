# FAQ - service-guardian

**Q: What problem does this actually solve?**
A: Helps SaaS platform teams control ownership handoffs in platform workflows with measurable guardrails.

Pain point: Teams lose time and confidence because ownership handoffs still depends on scattered manual checks.

**Q: Free to run?**
A: Yep. Supabase - $0/mo. See `terraform/INFRA_REQUIREMENTS.md`

**Q: Production ready?**
A: Yes - SLOs, security hardening, DR runbook, Helm, Terraform, monitoring.

**Q: Stack?**
A: Backstage, Crossplane, ArgoCD, Kubernetes Operators, Vault

**Q: What infra do I need?**
A: `terraform/INFRA_REQUIREMENTS.md` has the full breakdown - CPU/RAM/storage/network/cost.
